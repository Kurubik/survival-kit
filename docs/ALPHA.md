# Путник — первая Android alpha

Нативное русское приложение в выбранном оформлении: локальные памятки, сценарный спутник, голос, карта Латвии, снаряжение, заметки и экран помощи.

Эта публикация создаётся только после успешной сборки, семи unit-проверок движка, Android lint и пяти Android emulator UI-проверок. Скриншоты получены из Android-эмулятора; они не являются AI-концептами. Перед установкой можно сверить SHA256SUMS.

Пакеты устанавливаются по нажатию в «Рюкзаке»: Vosk RU 46.2 МБ; карта Латвии 110.2 МБ; Qwen3 4B 2.50 ГБ. Карточки и текстовый режим уже включены в APK. Для озвучки требуется установленный русский офлайн-голос Android.

Ограничения: это debug-signed alpha, не production-релиз. Качество реальной речи, TTS на конкретном телефоне, локальные AI-ответы, батарея, полевой GPS и медицинская редактура пока не подтверждены. Нет гарантии обновления поверх прошлых CI-подписей, текущих костровых ограничений, безопасной маршрутизации, фонового трека или спутникового SOS. Литва/Эстония пока не включены.

Не рассматривайте alpha как единственное средство навигации, связи или первой помощи.
